## How to Run the Projects

1. Clone or download this repository.
2. Open the required homework folder.
3. Open any `.html` file in a web browser.
4. For pages using external CSS, keep the related CSS files in their original locations.
5. For pages using video backgrounds, ensure the video files remain in their respective `vid` folders.
